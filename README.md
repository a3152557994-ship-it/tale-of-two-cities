# 1792：断头台城门官 — 双城记生死验关

> *“It was the best of times, it was the worst of times…”*
> **1792 年加来城门，今晚有三个人急着登船去伦敦——拿好你的放大镜和生死印章，90% 的人第一审就盖错章。**

🌐 在线直接试玩：**https://a3152557994-ship-it.github.io/tale-of-two-cities/**

## 核心玩法（3 秒上手 · 零原著阅读门槛）

- **🔍 照妖放大镜**：按住拖动黄铜放大镜（2.25× 实时光学放大），照出粗麻头巾下的**南洋珍珠耳坠**、披肩暗藏的**波旁皇室金百合**、指甲缝里的**棺材铁锈**，以及白色领巾上的**药房乙醚迷药**。
- **📄 核验通行证 & 🧳 撬箱搜身**：点击核查前朝涂改假税章，撬开随身行李木桶搜出**侯爵府私印地契**、**台尔森真火漆外交公函**与**悉尼·卡顿的诀别绝笔**。
- **💰 贿赂诱惑 vs 🟢🔴 双印章重锤**：铁证面前嫌犯会推出 50 金币求饶（而你家里女儿正发烧缺药钱）——是盖下 **🟢 准予出关**，还是 **🔴 押上断头台**？放走贵族或冤杀特使累计 2 次记过，你自己就将成为第 53 名死囚。
- **黄金三审戏剧弧**：
  1. **第一审 · 夜雾渡船客**：扮成洗衣妇潜逃的侯爵表侄女（验伪装 + 50 金币救女诱惑）
  2. **第二审 · 满手坟土的怪客**：长得像盗墓贼、实则持外交豁免真公函的杰瑞（防无脑乱杀反转）
  3. **终局第三审 · 下午三点的替身马车**：拿着卡顿真护照、浑身乙醚味的越狱死囚达内——看穿调包后，你盖红章立头功升官，还是盖绿章成全文学史上最伟大的一次替死？

## 技术架构

- **规则与视图彻底分离**：[`GatekeeperCore.js`](src/game/GatekeeperCore.js) 纯逻辑零 DOM 依赖，可直接迁入抖音/微信小游戏纯画布层。
- **WebGL 双城油画裂隙背景**：[`PaintedTearEngine.js`](src/engine/PaintedTearEngine.js) 实时驱动雨雾与火光余烬，随绿章/红章切换英法双城心境，低端机自动降级至 DOM 层。
- **双构建目标**：
  - `pnpm build` → 输出 Web 版至 `docs/`（GitHub Pages）
  - `pnpm build:minitool` → 输出小红书离线小工具包 `release/双城记-撕裂年代-minitool.zip`（含相册存图与卡片分享适配，平台审计 0 警告）
