## 玩法

1. **扉页**：六组开篇对句，伦敦半句与巴黎半句分色；点亮词注可听英音朗读。
2. **裂隙**：拖动中央红色封蜡。四件信物（苏豪的窗 ↔ 碎酒桶与 BLOOD、多佛驿车 ↔ 侯爵金马车、圣保罗 ↔ 巴士底、泰尔森信使 ↔ 德发日夫人）会随裂隙越过而翻转。
3. **档案**：点信物打开羊皮纸档案（画面局部特写 + 狄更斯原文 + 中译 + 注释），一键「撕到对岸」看同一处在另一座城的样子。
4. **密信**：翻满 4 份档案后启封泰尔森银行的火漆急件，把黄铜游标拨到正确年份，显影 “RECALLED TO LIFE”。

## 技术

- 零运行时依赖：原生 WebGL 单 pass 着色器（[`PaintedTearEngine.js`](src/engine/PaintedTearEngine.js)），JS 包 ~20 KB gzip。
- 装饰纹样全部程序生成（[`ornaments.js`](src/ui/ornaments.js)）；音频为 Web Audio 实时合成（[`ChamberScore.js`](src/audio/ChamberScore.js)）。
- 支持中英对照 / 英文原著 / 中文译本切换、油画 / 铜版画两种渲染、手机竖屏（拖动画面平移 + 底部档案抽屉）。

```bash
pnpm install && pnpm dev     # 本地开发
pnpm build                   # 输出到 docs/（GitHub Pages）
```

## 素材来源

狄更斯《双城记》(1859) 为公版作品。三幅场景油画于 2026-11-15 使用 AI 图像生成工具（gpt-image-2）制作；代码、界面与中文文本为本项目编写。
